# Roadmap — mini-swin

> Generated by the **wayfinder** skill. This is the shared phase map for all
> agent sessions working on this project.

---

## Phase 1 — Scaffold `[done]`

Create the full directory skeleton, stub files, domain glossary (`CONTEXT.md`),
architecture decision records, and handoff docs. **No implementation code.**

## Phase 2 — Core Model `[next]`

Implement the Swin Transformer architecture from scratch in
`backend/model/swin_transformer.py`:

- Patch Embedding
- Window-based Multi-Head Self-Attention (W-MSA / SW-MSA)
- Swin Block (attention → LN → MLP → LN)
- Patch Merging between Stages
- Full 4-Stage backbone + classification head
- `SwinConfig` dataclass for Variant selection (T / S / B / L)
- Unit tests for shape correctness at every stage

## Phase 3 — Training Pipeline `[pending]`

Build the training loop in `backend/training/`:

- Dataset loading (CIFAR-10 / Tiny-ImageNet)
- Augmentation pipeline (RandAugment, MixUp, CutMix)
- Label-smoothing cross-entropy loss
- Cosine annealing + linear warm-up scheduler
- Checkpoint saving & resumption
- Metrics logging (Top-1 / Top-5 accuracy)

## Phase 4 — FastAPI Serving `[pending]`

Wire the trained model to a REST API in `backend/api/`:

- `POST /predict` — accept image, return Top-5 Prediction
- `GET /health` — liveness + model-loaded check
- `POST /train/start` — trigger training run (async)
- Model Manager singleton for loading/caching Checkpoints
- CORS middleware, request schemas, error handling

## Phase 5 — React Frontend `[pending]`

Build the Vite + React UI in `frontend/`:

- Image Uploader (drag-and-drop)
- Prediction Card (Top-5 confidence bars)
- Training Chart (live loss/accuracy via SSE or polling)
- Model Selector (Variant picker)
- Pages: Home, Train, Results

## Phase 6 — Docker & CI `[pending]`

- Finalise `Dockerfile.backend` and `Dockerfile.frontend`
- Complete `docker-compose.yml` with health checks
- GitHub Actions CI: lint (ruff + eslint), type check, unit tests
- README badges and usage instructions
